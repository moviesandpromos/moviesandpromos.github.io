Entry & Exit Conditions

Every strategy has rules for when to buy and when to sell. Each condition below comes from the stock's technical indicators. You choose which conditions must be true to enter a trade, and which must be true to exit. Do not treat any single value as an automatic buy or sell signal.

How conditions combine

Each condition you enable is joined with the previous one using AND or OR.

AND means both must be true. OR means either one is enough. You can mix AND and OR — StockWise evaluates them left-to-right.

Event vs State

Some conditions are events — they fire on the day something happens (for example, RSI crosses above 30).

Others are states — they describe the current situation (for example, daily trend is UP). States remain true until they change.

Neutral is not a sell signal

Values like UNCHANGED WITHIN_RANGE NEUTRAL STABLE_OBV NA mean there is no new signal. They do not automatically close a position.

The 11 Conditions

RSI

Relative Strength Index
Values

A number between 0 and 100. Default entry: 30. Default exit: 70.

Type

Event

What it means

Measures how fast prices have moved recently. Below 30 is often considered oversold; above 70 overbought.

How to use

Typical entry: RSI crosses above 30. Typical exit: RSI crosses above 70.

Beginner tip

A stock can stay below 30 during a strong downtrend. Combine with trend filters to avoid catching a falling knife.

DMA Trend

Moving Average Trend (Daily / Weekly / Monthly)
Values

UPDOWN

Type

State / Filter

What it means

Shows the direction of the trend on daily, weekly, or monthly charts.

How to use

Typical entry filter: Daily UP and Weekly UP. Typical exit: Daily DOWN.

Beginner tip

Trends take time to change. Weekly and monthly signals are slower but more reliable than daily.

MACD

Moving Average Convergence Divergence
Values

positive_crossnegative_crossunchanged

Type

Event

What it means

positive_cross means the MACD line crossed above its signal line (bullish momentum). negative_cross is the opposite.

How to use

Typical entry: positive_cross. Typical exit: negative_cross.

Beginner tip

unchanged simply means no crossover today. It is not a sell signal.

Bollinger Band

Bollinger Bands
Values

near_uppernear_lowerwithin_range

Type

State

What it means

Describes where the price sits relative to a volatility band around a moving average.

How to use

Mean reversion: enter near_lower, exit near_upper. Trend following: enter near_upper (with other confirmations).

Beginner tip

within_range means the price is not near either band. It is not an exit signal.

Strategy Signal

StockWise Strategy Classification
Values

NEUTRAL_SETUPTECHNICAL_REVERSIONTREND_MOMENTUM_CONFIRMATIONEARLY_MOMENTUM

Type

State / Filter

What it means

A higher-level snapshot of what kind of setup the stock is in.

How to use

Use as an entry filter, e.g. Strategy Signal = TECHNICAL_REVERSION.

Beginner tip

NEUTRAL_SETUP means no strong setup. It should not trigger a trade.

Breakout Signal

Breakout Detection
Values

YESNO

Type

Event

What it means

YES means a breakout was detected that day.

How to use

Entry trigger. Add a confirmation filter (trend UP, OBV rising) since breakouts are volatile.

Beginner tip

NO on the next day does not mean the breakout failed. It means no NEW breakout occurred.

OBV

On-Balance Volume Signal
Values

RISING_OBVFALLING_OBVSTABLE_OBV

Type

Filter / Confirmation

What it means

Rising OBV suggests buying pressure. Falling OBV suggests selling pressure.

How to use

Use RISING_OBV to confirm an entry. FALLING_OBV can be an optional exit.

Beginner tip

STABLE_OBV means no clear direction — not a reason to exit.

VWAP

Volume-Weighted Average Price (End-of-Day)
Values

BULLISHBEARISHNEUTRAL

Type

Filter / Confirmation

What it means

BULLISH means the closing price is above the VWAP. BEARISH means below.

How to use

Use BULLISH to confirm a long entry. BEARISH can be an optional exit.

Beginner tip

This is an end-of-day VWAP, not the intraday one used by day traders.

ADX

Average Directional Index
Values

STRONGWEAKNO_TREND

Type

Trend-Strength Filter

What it means

Measures how strong the trend is, not its direction.

How to use

Use STRONG to confirm entries in a trend-following strategy.

Beginner tip

A STRONG ADX can occur in an uptrend or a downtrend. Always combine with a directional filter.

Stochastic

Stochastic Oscillator
Values

OVERSOLDOVERBOUGHTNEUTRAL

Type

State / Context

What it means

Shows where the price is within its recent range.

How to use

Reversal strategies: enter on OVERSOLD, exit on OVERBOUGHT.

Beginner tip

A stock can stay overbought during a strong rally. Combine with trend filters.

Candle Pattern

Bullish / Bearish Engulfing
Values

BULLISH_ENGULFINGBEARISH_ENGULFINGNA

Type

Event

What it means

A single-candle or two-candle pattern that can indicate a reversal.

How to use

Entry trigger (bullish) or exit trigger (bearish).

Beginner tip

NA means no pattern was detected. It is not an exit.
